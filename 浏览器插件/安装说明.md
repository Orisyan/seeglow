# 拾光浏览器插件 · 安装说明

在B站视频页右上角添加「✦ 拾光总结」按钮，点击直接把当前视频发给本机的拾光软件开始总结（需先启动拾光网页版或封装版）。

## 安装（Chrome / Edge，一次性）

1. 打开浏览器扩展管理页：
   - Chrome 地址栏输入 `chrome://extensions`
   - Edge 地址栏输入 `edge://extensions`
2. 打开右上角「开发者模式」
3. 点「加载已解密的扩展程序」，选择本文件夹（浏览器插件）
4. 打开任意B站视频页，右下角出现橙色「✦ 拾光总结」按钮即成功

## 使用

1. 先启动拾光（网页版 `python -m seeglow --web`，或封装版双击 EXE）
2. 在B站看到想总结的视频 → 点右下角「拾光总结」
3. 浏览器打开拾光页面并自动开始总结

## 常见问题

- **点了没反应 / 打不开页面**：拾光没在运行（默认地址 http://127.0.0.1:8765 ）
- **不想用了**：扩展管理页移除，或暂时关闭
